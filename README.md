## Factory bank

110 presets, 10 in each category:

**LEAD · PAD · KEYS · CHORD · STRINGS · BASS · PLUCK · BRASS · TEXTURE · BELL · PERC**

The bank is built into the plugin. Factory presets switch directly; generation displays its own loading indicator.

## Features

- Blend Analog and FM with one MIX control.
- Generate sounds by category and keep or revisit results.
- Independent Mod Wheel assignments, including modulation speed and effect controls.
- MIDI Learn for RANDOM.
- Adaptive CPU protection for dense and overlapping passages.
- VST3 plugin and standalone application on all platforms; AU on macOS.

The plugin is named **earsynth** and the VST3 is installed in the **Alex Ears** folder. User presets are preserved when updating.

## Installation

Close your DAW before installing. Open the installer for your platform, then reopen the DAW and rescan plugins if necessary.

The macOS and Windows builds do not have a commercial signing certificate. See [INSTALL.md](INSTALL.md) for platform security prompts and installation paths.

This repository contains downloads and documentation. The source code is private.
