# Changelog

## 1.01

### macOS installer revision 2 — 17 October 2026

Use a standard PKG inside the DMG; replace old quarantined plugin copies while preserving user presets and backups; refresh Audio Unit registration. Audio binaries remain identical to 1.01.

Release by Alex Ears with a 110-preset factory bank, STRINGS and PERC categories, one Analog/FM MIX control, expanded Mod Wheel assignments, MIDI Learn for RANDOM, direct ready-preset loading and adaptive CPU protection.

Installers are provided for macOS Universal, Windows x64 and Linux x86_64. See [RELEASE_NOTES.md](RELEASE_NOTES.md).
