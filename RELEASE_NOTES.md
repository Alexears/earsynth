# earsynth 1.01

**By Alex Ears**

- 110 curated factory presets: 10 in each of 11 categories.
- STRINGS category with six string models.
- PERC category with kick, snare, hat, tom, clap and tuned percussion models.
- A single MIX control for Analog, FM and their blend.
- Independent Mod Wheel routing with editable modulation speed and effect controls.
- MIDI Learn for RANDOM; generation loading is shown for mouse and MIDI generation.
- Direct switching of ready factory presets.
- Adaptive CPU protection retained for overlapping notes and fast passages.
- Unified product naming: **earsynth 1.01**, by **Alex Ears**.

## Builds

- macOS Universal: VST3, AU and Standalone in an automatic DMG installer.
- Windows x64: VST3 and Standalone, Setup.exe and portable ZIP.
- Linux x86_64: VST3 and Standalone, DEB and tar.gz.

The 110-preset bank is embedded in every build. User presets are preserved during installation and updates.

The macOS build is ad hoc signed and not notarized; the Windows build is unsigned. Installation instructions and platform security prompts are described in [INSTALL.md](https://github.com/Alexears/earsynth/blob/main/INSTALL.md).

Source code is private.
